# Texture source material

This directory contains editable templates and other working source images.
Files here are not compiled into the game automatically. Finished replacements
belong under `assets/texture_overrides/` at their complete archive locator path.

`status-label-blank.png` is the shared 32x16 plate used to author the English
status-label textures under `assets/texture_overrides/pa/000031/`.
